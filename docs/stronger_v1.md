# stronger 项目计划 v1

## 产品核心

`stronger` 是一个帮助用户聚焦方向、执行关键行动、并由 AI 陪伴完成成长闭环的网站。

## 第一版范围

- 单页滚动式产品结构
- 首页第一屏为大仪表盘
- 三条人生主线：生命 / 爱 / 事业
- 当前 30 天目标作为行动中心
- AI 聚焦、安排今天、复盘今天、周总结
- 首次使用弹窗引导

## 首页结构

1. 第一屏大仪表盘
2. 当前目标区
3. 今日记录区
4. AI 反馈区
5. 本周复盘区
6. 历史趋势区

## 首次使用流程

1. 三条主线打分
2. 三条主线阶段标签选择
3. 输入未来 30 天目标
4. 选择当前最大阻碍
5. AI 生成起步建议

## 技术方向

- Next.js + TypeScript
- Tailwind CSS
- Recharts
- 通过兼容接口接入千问
- 第一版不接数据库，使用 mock 数据和会话态

## 部署方向

- 阿里云 ECS
- Nginx 反代
- PM2 保活
- 通过公网 IP 访问
